# 🎲 TG Random Bot

Telegram бот, который отвечает на случайное сообщение в группе по команде `/random`.

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и список команд |
| `/settings` | Настройка диапазона ID сообщений |
| `/random` | Ответить на случайное сообщение из диапазона |

## Деплой на Vercel

### 1. Создай бота у @BotFather

1. Напиши `/newbot` в @BotFather
2. Следуй инструкциям, получи **токен**
3. Важно: зайди в настройки бота → **Group Privacy → отключи** (чтобы бот видел сообщения в группе)

### 2. Задеплой на Vercel

```bash
# Установи Vercel CLI (если нет)
npm i -g vercel

# Задеплой
vercel --prod
```

Или через GitHub:
1. Залей папку в репозиторий
2. Подключи репо в [vercel.com](https://vercel.com)
3. Vercel автоматически задеплоит

### 3. Добавь переменную окружения

В Vercel Dashboard → Settings → Environment Variables:

```
BOT_TOKEN = <твой токен от BotFather>
```

### 4. Зарегистрируй webhook

После деплоя выполни:

```bash
BOT_TOKEN=xxx node setup-webhook.js https://ИМЯ-ПРОЕКТА.vercel.app
```

Или просто открой в браузере (замени токен и URL):
```
https://api.telegram.org/botТВОЙ_ТОКЕН/setWebhook?url=https://ИМЯ-ПРОЕКТА.vercel.app/api/webhook
```

### 5. Добавь бота в группу

1. Добавь бота в свою группу
2. Дай ему права администратора (чтобы он мог читать историю)
3. Напиши `/settings` для настройки диапазона
4. Пиши `/random` — бот ответит на случайное сообщение!

## Как работает диапазон

`/settings` показывает клавиатуру с кнопками ➕/➖ и ручным вводом.

Например, если в группе ~5000 сообщений — ставь `от: 1, до: 5000`.  
Бот возьмёт рандомный ID из этого диапазона и ответит на то сообщение.

> ⚠️ **Важно:** настройки хранятся в памяти Vercel-функции. При холодном старте (redeploy или долгое отсутствие запросов) сбрасываются. Для постоянного хранения подключи [Vercel KV](https://vercel.com/docs/storage/vercel-kv) или [Upstash Redis](https://upstash.com/).

## Ссылки на сообщения

Формат ссылки: `https://t.me/c/АЙДИ_ГРУППЫ/АЙДИ_СООБЩЕНИЯ`

Бот автоматически убирает префикс `-100` из chat_id для формирования корректной ссылки.
